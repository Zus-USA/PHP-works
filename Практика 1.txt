1. Убедитесь, что PHP установлен (php -v).


2. Создайте файл main.php.


3. Выведите строку Hello, PHP! с помощью echo.

Задание 2. Строгая типизация

1. В начале файла добавьте:

declare(strict_types=1);


2. Создайте функцию:

function sum(int $a, int $b): int {
    return $a + $b;
}


3. Вызовите sum(2, 3) и проверьте результат.


4. Попробуйте вызвать sum("2", 3) — что произойдет?

Задание 3. Обработка ошибок деления

Создайте функцию:

function divide(float $a, float $b): ?float {
    return $b === 0.0 ? null : $a / $b;
}

1. Проверьте работу при b = 0.


2. Выведите "Ошибка деления на ноль", если результат null.




---

Задание 4. Оператор match

1. Напишите функцию grade(int $score): string, которая возвращает оценку:

return match (true) {
    $score >= 90 => 'A',
    $score >= 75 => 'B',
    $score >= 60 => 'C',
    default => 'F',
};


2. Проверьте для значений 95, 70, 50.

Задание 5. Null-safe оператор

1. Создайте объект $user = null;.


2. Попробуйте вызвать $user?->getName();.


3. Объясните, чем это отличается от $user->getName();.

2. С помощью array_map(fn($n) => $n ** 2, $numbers) создайте массив квадратов.


3. Напишите стрелочную функцию, возвращающую "Число X — четное/нечетное".

Задание 7. Мини-задача “FizzBuzz”

1. Напишите скрипт quiz.php, который:

Принимает число n через $_GET.

Если делится на 3 — выводит "Fizz".

Если на 5 — "Buzz".

Если на 15 — "FizzBuzz".

Иначе выводит само число.




Пример:

php -S localhost:8000
http://localhost:8000/quiz.php?n=30
