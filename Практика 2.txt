Задание 12. Класс StringUtils

1. Создайте статический метод:

class StringUtils {
    public static function isPalindrome(string $s): bool {
        $s = mb_strtolower(preg_replace('/\s+/', '', $s));
        return $s === strrev($s);
    }
}
